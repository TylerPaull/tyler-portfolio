TYLER PAUL LIPMAN PORTFOLIO - STATIC SITE (made with Claude, November 2026)

WHAT THIS IS
A complete, self-contained static website: 15 HTML pages plus an images/ folder.
Every page is plain HTML with inline styles. No build step, framework, or
JavaScript is required. The only external request is Google Fonts
(Bricolage Grotesque, Inter, IBM Plex Mono).

INSTRUCTIONS FOR THE ASSISTANT UPDATING tylerpauldesg.com
- This set REPLACES the current portfolio design. Do not merge it with the old
  layout, restyle it, or regenerate the images.
- Keep the page copy, image files, and layout as supplied. All images are
  Tyler's original files (no AI regeneration was done here).
- index.html is the home page. All links between pages are relative, so the
  folder can be deployed as-is to any static host, or its pages adapted into
  the existing site's routing (update the links if file names change).
- Keep alt text and captions; they are written for accessibility.
